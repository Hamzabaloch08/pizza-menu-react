# 🍕 Fast React Pizza Co.

A responsive React app displaying a pizza menu with Tailwind CSS. Includes quantity tracking and visual cues for sold-out items.

## 🚀 Features

- Responsive layout with Tailwind CSS
- Grayscale effect on sold-out pizzas
- Clean, mobile-friendly design
- Modular component structure

## 🧩 Components

- **App.jsx**: Main layout with header, description, button, and `<Card />`
- **Card.jsx**: Renders each pizza item with image, name, description, and quantity
